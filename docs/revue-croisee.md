# Revue croisée — à remplir par les deux équipes

Statut : non réalisée. Le test automatique d'un clone propre ne remplace pas cette revue.

| Information | Résultat |
|---|---|
| Équipe qui teste / équipe propriétaire | À compléter |
| URL du dépôt et commit testé | À compléter |
| Système et version Docker/Compose | À compléter |
| Commande 1 : clone du dépôt | À compléter |
| Commande 2 : bin/dev adapté au système | À compléter |
| Archive JSON produite et nombre d'articles | À compléter |
| Résultat bin/test | À compléter |
| Premier bug rencontré et reproduction | À compléter |
| Correctif, nouveau test et date de validation | À compléter |

Joindre les sorties utiles sans secrets. Refaire la procédure sur le dépôt de l'autre équipe.
